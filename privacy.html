LoveTone Uploader - Privacy Policy

Last updated: November 2026

What this app is

LoveTone Uploader is a personal automation tool operated by the owner of the LoveTone Music YouTube channel (youtube.com/@LoveToneMusic41). It is used only by the channel owner, to upload the owner's own videos to the owner's own channel.

Google user data we access

With the owner's permission the app uses the YouTube Data API with these scopes:

  • youtube.upload - to upload videos and set thumbnails on the owner's channel.
  • youtube.readonly - to confirm which channel is signed in and to check the owner's own recent uploads, so the same video is never uploaded twice.

How the data is used and stored

The app does not collect, sell, share or publish any personal data of other people. It has no other users. The only credential it keeps is an OAuth refresh token belonging to the owner, stored as an encrypted secret in the owner's private GitHub repository settings. It is used only to run the upload and is never shown or shared.

YouTube and Google policies

Use of YouTube API Services is subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

The owner can revoke the app's access at any time at myaccount.google.com/permissions.

Contact

Please contact the LoveTone Music channel via the About tab of youtube.com/@LoveToneMusic41.
